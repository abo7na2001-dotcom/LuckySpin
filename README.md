# LuckySpin

تصميم لعبة "Lucky Spin" احترافية باستخدام HTML و CSS و JavaScript.

## التشغيل

1. افتح ملف `index.html` في المتصفح.
2. اضغط على زر "ابدأ العجلة".
3. استمتع بالعجلة واحتفظ بالرصيد.

## المميزات

- تصميم أنيق واحترافي
- عجلة دوارة متحركة
- جوائز متنوعة
- نظام رصيد Coins
- تأثيرات confetti عند الفوز

## الملفات

- `index.html` — هيكل الصفحة
- `styles.css` — التنسيق والرسوم
- `script.js` — منطق اللعبة

## ملاحظات

يمكنك لاحقاً توسيع المشروع إلى نسخة React أو Next.js أو ربطه بواجهة API.
